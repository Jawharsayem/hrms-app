# Human Resource Management System (HRMS)

### Enterprise HR Management Solution | Mobile Application & Backend System

A custom Human Resource Management System developed for an organization operating in the diplomatic sector. The solution comprises a Flutter-based mobile application and a dedicated backend service, supported by Microsoft Azure cloud infrastructure.

The project focuses on delivering an integrated digital platform for organizational HR operations through mobile application development, backend services, cloud deployment, and secure application access.

---

## 1. Project Overview

The Human Resource Management System (HRMS) is a custom software solution designed to support human resource management activities within an institutional environment.

The system follows a client-server architecture, combining a Flutter-based mobile application with a separately maintained backend service. This architecture enables communication between the mobile interface and server-side components through API integration.

The development involved multiple areas of software engineering, including application development, backend API implementation, cloud environment configuration, authentication, deployment, and system integration.

### Project Objectives

- Digitize and streamline organizational HR operations.
- Provide a dedicated mobile application interface.
- Establish reliable communication between frontend and backend services.
- Implement authentication and authorization mechanisms.
- Utilize cloud infrastructure for backend deployment.
- Develop an integrated and maintainable application architecture.
- Improve accessibility to HR-related application workflows.

---

## 2. System Architecture

The HRMS solution is structured around interconnected application and infrastructure components.

### Mobile Application

The Flutter-based mobile application serves as the user-facing component of the system. It provides the interface for accessing application functionality and communicating with backend services.

### Backend Service

The JavaScript-based backend provides server-side functionality, handles application requests, and supports communication between the mobile application and associated services.

### Cloud Infrastructure

Microsoft Azure was used as part of the backend infrastructure. Development contributions included Azure environment configuration, setup, and backend deployment through Azure App Service.
